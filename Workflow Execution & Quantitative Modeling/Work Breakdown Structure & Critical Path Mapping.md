Engineered Specification: Work Breakdown Structure & Critical Path Mapping

Task: Transform an ambiguous, complex corporate deliverable into a phased Work Breakdown Structure (WBS) with identified critical paths, dependencies, and immediate entry-point actions.

Deliverable Scope:
- Core Objective: [e.g., Execute an enterprise compliance audit across 4 disparate internal software platforms]
- Available Time Horizon: [e.g., 3 weeks until auditor intake]
- Dedicated Weekly Capacity: [e.g., 12 hours per week]
- Key Collaborators/Departments: [e.g., SecOps, Internal Legal, IT Infrastructure]

Decomposition Rules:
1. Sequence actions using a strict critical path logic, highlighting tasks that block subsequent actions.
2. Isolate administrative prerequisites (e.g., credentials, permissions, system access) from analytical execution tasks.
3. Define concrete "Exit Criteria" for each stage specifying what artifact proves the phase is complete.
4. Incorporate a "20-Minute Anti-Inertia Entry Point" consisting of two immediate friction-free actions executable without external approvals.

Output Architecture:
1. Immediate Activation: Exactly two friction-free actions requiring under 20 minutes to generate working momentum.
2. Phased Work Breakdown Schedule: Markdown table with columns [Phase | Task Description | Blocking Dependencies | Estimated Effort (Hrs) | Hard Exit Criteria].
3. Risk & Delay Trigger Points: Bullet points noting where external friction is guaranteed to stall progress and how to preempt it.
